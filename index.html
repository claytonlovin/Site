Perguntas Frequentes (FAQ)

O WInsight precisa alterar meu Winthor ou ERP? +

O WInsight conecta-se apenas para leitura de dados, via API segura. Ele não faz alterações ou modificações no seu banco de dados Winthor, garantindo total segurança e estabilidade.

Quem terá acesso aos meus dados de faturamento? +

Apenas sua empresa. Garantimos confidencialidade total. Não há compartilhamento de informações comerciais ou estratégicas com terceiros.

O sistema é difícil de usar para gestores não técnicos? +

Absolutamente não. O WInsight foi projetado para gestores, com foco em simplicidade. Você recebe insights e recomendações em linguagem clara, sem precisar ser um especialista em dados.
